## CAPÍTULO 1 - INTRODUCCIÓN AL SISTEMA

### 1.1 ¿Qué es CRM Monarca?

CRM Monarca es una plataforma tecnológica desarrollada específicamente para empresas de transporte. Integra todos los procesos operativos en una sola interfaz web, desde la creación de embarques hasta la facturación final, proporcionando control total sobre la operación.

### 1.2 Beneficios del Sistema

**🚀 Para la Operación:**
- Digitalización completa de procesos manuales
- Seguimiento en tiempo real de embarques
- Optimización de recursos (operadores y vehículos)
- Reducción de errores y tiempos muertos

**💰 Para las Finanzas:**
- Facturación automatizada con cálculos precisos
- Control de cuentas por cobrar en tiempo real
- Reportes financieros instantáneos
- Reducción de cuentas incobrables

**📊 Para la Gerencia:**
- Dashboard ejecutivo con métricas clave
- Reportes personalizables por área
- Auditoría completa de todas las operaciones
- Análisis de tendencias y proyecciones

### 1.3 Módulos del Sistema

| Módulo | Función Principal | Usuarios Típicos |
|--------|-------------------|------------------|
| **📦 Embarques** | Crear y gestionar servicios de transporte | Coordinadores, Supervisores |
| **👥 Operadores** | Administrar conductores y documentación | Recursos Humanos, Operaciones |
| **🚛 Asignaciones** | Dispatch y control de recursos | Dispatchers, Coordinadores |
| **🚚 Flotas** | Gestión de camiones y remolques | Mantenimiento, Operaciones |
| **� Clientes** | Base de datos comercial | Ventas, Servicio al Cliente |
| **💰 Facturación** | Proceso de cobro y facturación | Facturación, Contabilidad |
| **📸 Evidencias** | Documentación fotográfica | Operadores, Control de Calidad |
| **⏰ Recordatorios** | Alertas y vencimientos | Todos los usuarios |
| **⚙️ Configuración** | Administración del sistema | Administradores IT |

### 1.4 Roles y Permisos

**🔐 ADMINISTRADOR**
- Acceso completo a todas las funciones
- Gestión de usuarios y permisos
- Configuración del sistema
- Auditoría y reportes globales

**📋 COORDINADOR OPERATIVO**
- Gestión completa de embarques
- Asignación de operadores y vehículos
- Seguimiento de entregas
- Reportes operativos

**💰 FACTURACIÓN**
- Módulo de facturación completo
- Control de cuentas por cobrar
- Reportes financieros
- Gestión de clientes (datos fiscales)

**👀 CONSULTA**
- Solo lectura de información
- Reportes básicos
- Sin permisos de modificación

## CAPÍTULO 2 - ACCESO Y NAVEGACIÓN

### 2.1 Requisitos del Sistema

**🌐 Navegadores Compatibles:**
- Google Chrome (recomendado)
- Mozilla Firefox
- Microsoft Edge
- Safari (macOS/iOS)

**💻 Requisitos Mínimos:**
- Conexión a internet estable
- Resolución mínima: 1024x768
- JavaScript habilitado
- Cookies permitidas para el sitio

### 2.2 Proceso de Inicio de Sesión

**Paso a Paso:**

1. **Abrir navegador web**
2. **Navegar a:** `https://crm.transportesmonarca.com`
3. **Completar formulario de acceso:**
   ```
   👤 Usuario: [tu_usuario]
   🔐 Contraseña: [tu_contraseña]
   ```
4. **Hacer clic en "INICIAR SESIÓN"**

### 2.3 Seguridad del Sistema

**🔒 Políticas de Seguridad:**
- **Timeout de sesión:** 30 minutos de inactividad
- **Intentos fallidos:** Máximo 3 antes de bloqueo temporal
- **Bloqueo temporal:** 15 minutos automático
- **Auditoría completa:** Todas las acciones se registran

**⚠️ Buenas Prácticas:**
- No compartir credenciales con otros usuarios
- Cerrar sesión al terminar el trabajo
- Usar contraseñas seguras (8+ caracteres)
- Reportar actividad sospechosa inmediatamente

### 2.4 Recuperación de Acceso

**Si olvidaste tu contraseña:**
1. Contactar al Administrador del Sistema
2. Proporcionar tu nombre de usuario
3. Verificar tu identidad
4. Recibir contraseña temporal
5. Cambiar contraseña en primer acceso

**Si tu cuenta está bloqueada:**
- Esperar 15 minutos para desbloqueo automático
- O contactar Soporte Técnico para desbloqueo manual

## 4. Gestión de Embarques

### Crear Nuevo Embarque

#### Información Básica
1. **Clic en "Nuevo Embarque"**
2. **Completar campos:**
   - **Folio:** Se genera automáticamente
   - **Cliente:** Seleccionar de lista desplegable
   - **Tipo Servicio:** Importación/Exportación/Nacional
   - **Fecha Recolección:** Calendario emergente
   - **Hora Recolección:** Formato 24 hrs

#### Direcciones
**Origen (Recolección):**
- Dirección completa
- Contacto y teléfono
- Horario de atención
- Observaciones especiales

**Destino (Entrega):**
- Dirección de entrega
- Contacto receptor
- Horarios preferidos
- Restricciones de acceso

**💡 Tip:** Para múltiples recolecciones, usar "Agregar Dirección"

#### Mercancía y Servicios
- **Descripción:** Detalle de la carga
- **Peso:** Toneladas o kg
- **Dimensiones:** L x A x H metros
- **Valor Declarado:** Para seguros
- **Servicios Especiales:** Maniobras, escolta, etc.

#### Precios
- **Flete Base:** Precio principal del servicio
- **Combustible:** % sobre flete base
- **Maniobras:** Servicios adicionales
- **Total:** Cálculo automático con impuestos

### Estados del Embarque

Los embarques siguen este flujo:

1. **🆕 Creado** → Recién registrado, editable
2. **⏳ Listo para Asignar** → Información completa
3. **👤 Asignado** → Operador y vehículo definidos
4. **🚛 En Tránsito** → Viaje iniciado
5. **✅ Completado** → Entregado con evidencias
6. **💰 Facturado** → Procesado para cobranza
7. **📁 Archivado** → Proceso finalizado

### Búsqueda y Filtros

#### Filtros Rápidos
- **Por Estado:** Multiselección disponible
- **Por Fechas:** Rango personalizable
- **Por Cliente:** Lista desplegable
- **Por Operador:** Conductores asignados

#### Búsqueda Avanzada
- **Texto libre:** Busca en observaciones
- **Múltiples criterios:** Combinar filtros
- **Exportar:** Descargar resultados en Excel

### Editar Embarques

**Reglas por Estado:**
- **Creado:** Edición completa
- **Listo p/Asignar:** Solo ajustes menores
- **Asignado:** Solo observaciones
- **En Tránsito+:** Solo consulta

## 5. Asignación de Operadores

### Proceso de Asignación

#### Paso 1: Seleccionar Embarque
- **Filtrar por estado** "Listo para Asignar"
- **Revisar información:** fechas, destino, carga
- **Clic en "Asignar"**

#### Paso 2: Elegir Operador
**Criterios de selección:**
- ✅ **Disponibilidad:** Sin asignación activa
- 📋 **Documentos vigentes:** Licencia, aptitud médica
- 🎯 **Experiencia:** Tipo de carga similar
- 📍 **Ubicación:** Cercano al origen

#### Paso 3: Asignar Vehículo

**Camión:**
- Verificar capacidad de carga
- Documentos al día
- Estado operativo

**Remolque:**
- **Propio:** Seleccionar de inventario
- **Externo:** Captura manual de placas
- **Sin remolque:** Para carga específica

#### Paso 4: Configurar Pagos
- **Porcentaje:** % sobre flete base
- **Monto fijo:** Cantidad específica
- **Gastos:** Combustible, casetas, viáticos
- **Anticipos:** Adelantos entregados

#### Paso 5: Confirmar
- **Revisar resumen completo**
- **Verificar fechas y horarios**
- **Confirmar asignación**

### Modificar Asignaciones

**Cambios permitidos:**
- Reasignar operador
- Cambiar vehículo
- Ajustar pagos
- Modificar fechas

**Proceso:**
1. Seleccionar embarque asignado
2. Clic en "Modificar Asignación"
3. Especificar motivo del cambio
4. Realizar ajustes necesarios
5. Confirmar modificación

## 8. Facturación y Cobranza

### Proceso de Facturación

#### Embarques Listos para Facturar
Solo aparecen embarques **"Completados"** con:
- ✅ Entrega confirmada por operador
- ✅ Fotos de evidencia subidas
- ✅ Información de precios completa
- ✅ Sin observaciones pendientes

#### Facturación Individual
1. **Buscar embarque** por folio o cliente
2. **Verificar datos** y servicios
3. **Clic en "Facturar"**
4. **Revisar totales** e información fiscal
5. **Generar factura** PDF
6. **Enviar por email** al cliente

#### Facturación Consolidada
**Para clientes con múltiples embarques:**
1. **Filtrar por cliente** y período
2. **Seleccionar embarques** del período
3. **Clic en "Facturar Seleccionados"**
4. **Agrupar conceptos** por tipo
5. **Generar factura consolidada**

### Control de Cobranza

#### Estados de Facturación
- 🕒 **Pendiente:** Recién facturada
- 📧 **Enviada:** Entregada al cliente
- 👀 **En Revisión:** Cliente verificando
- ⚠️ **Con Observaciones:** Comentarios del cliente
- ✅ **Pagada:** Cobranza completada
- ❌ **Vencida:** Fuera de términos

#### Panel de Cobranza
**Organizado por antigüedad:**
- 0-30 días: Vigentes
- 31-60 días: Atención
- 61-90 días: Seguimiento intenso
- +90 días: Gestión especial

#### Acciones de Cobranza
- **Llamadas:** Registrar seguimiento
- **Estados de cuenta:** Envío automático
- **Recordatorios:** Por email/WhatsApp
- **Escalamiento:** A gerencia o legal

### Reportes Financieros

**Disponibles:**
- Reporte de ventas por período
- Antigüedad de saldos
- Análisis de clientes
- Flujo de efectivo proyectado
- Performance de cobranza

## 9. Evidencias Fotográficas

### Importancia de las Fotos

Las evidencias fotográficas son **obligatorias** para:
- ✅ Completar el embarque
- 🛡️ Respaldo ante reclamaciones
- 📋 Auditorías de calidad
- 🤝 Transparencia con clientes

### Proceso de Subida

#### Acceso al Módulo
**Tres formas:**
1. Menú "Subir Fotos" → buscar embarque
2. Desde embarque específico → botón "Fotos"
3. Desde asignación → "Gestionar Fotos"

#### Tipos de Fotos Requeridas

**Recolección (mínimo 2 fotos):**
- Estado inicial de mercancía
- Proceso de carga
- Mercancía cargada y asegurada

**Entrega (mínimo 2 fotos):**
- Mercancía al llegar
- Proceso de descarga
- Documentos firmados (POD)

**Adicionales (recomendadas):**
- Sellos y candados
- Daños preexistentes
- Maniobras especiales

### Funciones Automáticas

#### Compresión Inteligente
- **Reducción de tamaño:** Hasta 80% sin perder calidad
- **Formatos aceptados:** JPG, PNG, WebP, HEIC
- **Conversión automática:** Al formato más eficiente

#### Metadatos Capturados
- **Fecha y hora:** Timestamp preciso
- **Ubicación GPS:** Coordenadas automáticas
- **Dispositivo:** Información del equipo
- **Usuario:** Quien subió la foto

### Validación y Control

**Validaciones automáticas:**
- Formato válido de imagen
- Tamaño máximo por archivo (10MB)
- Cantidad mínima (3 fotos por embarque)
- Calidad suficiente para evidencia

**Confirmación del operador:**
1. Revisar todas las fotos subidas
2. Verificar que sean correctas y completas
3. Agregar observaciones si es necesario
4. **Clic en "Confirmar Entrega"**

⚠️ **Importante:** Una vez confirmado, no se pueden modificar las fotos.

## 12. Solución de Problemas

### Problemas Frecuentes

#### No Puedo Iniciar Sesión
**Posibles causas y soluciones:**

❌ **Contraseña incorrecta**
✅ Verificar mayúsculas/minúsculas, contactar admin

❌ **Usuario bloqueado**  
✅ Esperar 15 min o contactar soporte técnico

❌ **Problemas de navegador**
✅ Limpiar caché, usar Chrome/Firefox actualizado

#### Las Fotos No Se Suben

❌ **Archivo muy grande**
✅ Comprimir imagen (<10MB) o usar formato JPG

❌ **Formato incompatible**
✅ Usar solo JPG, PNG, WebP

❌ **Conexión lenta**
✅ Verificar internet, intentar una foto por vez

#### No Encuentro Mi Embarque

❌ **Filtros activos**
✅ Limpiar todos los filtros, verificar fechas

❌ **Estado incorrecto**
✅ Revisar todos los estados disponibles

❌ **Búsqueda específica**
✅ Usar folio exacto o datos del cliente

#### El Sistema Está Lento

❌ **Muchas pestañas abiertas**
✅ Cerrar pestañas innecesarias, reiniciar navegador

❌ **Consulta compleja ejecutándose**
✅ Esperar unos minutos, simplificar filtros

❌ **Conexión de internet**
✅ Verificar velocidad, contactar ISP

### Mensajes de Error Comunes

**"Sesión Expirada"**
- Causa: Inactividad por más de 30 minutos
- Solución: Iniciar sesión nuevamente

**"No Tienes Permisos"**
- Causa: Intentas acceder a función no autorizada
- Solución: Contactar administrador

**"Error de Conexión"**
- Causa: Problemas de red o servidor
- Solución: Verificar internet, reintentar

**"Archivo Muy Grande"**  
- Causa: Excede límite de 10MB
- Solución: Comprimir archivo antes de subir
