## 🎬 Especificaciones Técnicas

### 📋 Estándares de Producción
- **Resolución:** 1920x1080 (Full HD)
- **Frame Rate:** 30 fps
- **Formato:** MP4 (H.264)
- **Audio:** 48kHz, estéreo
- **Duración:** 5-15 minutos máximo

### 🎯 Estructura Recomendada
1. **Intro** (30 seg): Logo + título + objetivos
2. **Contenido Principal** (80% del video)
3. **Recap** (1 min): Puntos clave + próximos pasos  
4. **Outro** (30 seg): Contacto + recursos adicionales

### 🛠️ Herramientas Sugeridas
- **Grabación:** OBS Studio (gratuito) o Camtasia
- **Edición:** Adobe Premiere, Final Cut, o DaVinci Resolve
- **Audio:** Audacity para post-producción
- **Hosting:** YouTube privado, Vimeo Business, o LMS interno

## 💡 Consejos para Grabación

### 🎤 Audio de Calidad
- Usar micrófono externo (no el de la laptop)
- Grabar en ambiente silencioso
- Hablar claro y pausado
- Hacer pause entre secciones

### 🖥️ Pantalla Limpia  
- Cerrar aplicaciones no necesarias
- Usar resolución estándar
- Configurar zoom apropiado
- Preparar datos de ejemplo realistas

### 🎭 Presentación
- Script preparado pero natural
- Ejemplos del mundo real
- Errores intencionados para enseñar recuperación
- Pausas para asimilación
